SBC NAV

Set up a new Windows PC once. Then update from MCDO whenever you need.

  1. Download the office setup EXE from MCDO. On an already connected office PC, choose Download ready-to-use office setup (.exe). Copy that one EXE to the new PC. It includes the private connection; no separate key file is needed.
  2. Run SBC-NAV-Office-Setup-2.2.0.exe. Finish installation, then click Set up and check this PC. Setup verifies the office connection and offers missing Chrome and IREPS Signer from their official sources. Follow the normal Windows installation screens.
  3. Connect your token and sign in to IREPS. Use the updater Chrome window. If your token driver is missing, use the manufacturer guidance shown in setup. Successful IREPS Payments access marks the PC ready.
  4. Open MCDO and click Update now. Sign in to IREPS in the updater Chrome window with your digital token. The update then continues.

Keep the PC on, connected to the internet, and the updater Chrome window open until MCDO confirms completion. You can return to MCDO to view progress or resume saved work.

Open SBC NAV → MCDO

If setup needs attention

The public installer needs private office authorisation. For the easiest setup, download the ready-to-use office EXE from a connected office PC. You can also select an existing private connection file under Recovery. Setup keeps completed steps and offers Retry after an interrupted download or installation. Google and IREPS sign-ins stay on each PC; they are not copied.

Open Start → SBC NAV → Set up this PC to connect again. Installing a newer version keeps saved progress.

Windows 10/11, 64-bit Intel/AMD. Python and the browser driver are included. No Codex is needed. Keep the office EXE private and share it only with authorised operators. Token vendor drivers and Windows administrator approval may be needed.
