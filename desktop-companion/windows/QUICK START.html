SBC NAV

Set up a new Windows PC once. Then update from MCDO whenever you need.

  1. Extract the complete ZIP. Keep the installer and SBC NAV Connection.sbcnav in the same folder.
  2. Install Chrome and your digital token software. Use Google Chrome and the token driver / signer supplied for your device.
  3. Run SBC-NAV-Setup-2.1.0.exe. Finish setup, then click Connect this PC. The connection file is detected automatically; no operator key needs to be typed.
  4. Open MCDO and click Update now. Sign in to IREPS in the updater Chrome window with your digital token. The update then continues.

Keep the PC on, connected to the internet, and the updater Chrome window open until MCDO confirms completion. You can return to MCDO to view progress or resume saved work.

Open SBC NAV → MCDO

If setup needs attention

Missing connection file? Extract the entire ZIP before running setup, or use Choose connection file. If a connection has expired, request a replacement file. Google and IREPS sign-ins stay on each PC; they are not copied.

Open Start → SBC NAV → Set up this PC to connect again. Installing a newer version keeps saved progress.

Windows 10/11, 64-bit Intel/AMD. Python and the browser driver are included. No Codex is needed. Keep the connection file private and share it only with authorised operators.
